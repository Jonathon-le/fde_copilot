## 任务

### 1. 创建目录结构

在 `D:\MyPython\fde_copilot` 下创建：

```text
fde_copilot/
├─ app/
│  └─ __init__.py        # 空文件即可
├─ scripts/
│  └─ __init__.py        # 空文件即可
├─ data/
│  └─ knowledge/         # 先空着，M1 放示例文档
├─ tests/                # 先空着
├─ requirements.txt
├─ .gitignore
└─ README.md
```

`__init__.py` 的作用是把目录标记成 Python 包。现在可以先理解为“让导入更稳定”，后面会讲清楚。

### 2. 编写 `app/config.py`

只使用标准库（`os`、`pathlib`），不要用第三方配置库。

要求：

1. 定义 `PROJECT_ROOT`，指向 `fde_copilot/` 项目根目录。
   - 提示：文件在 `app/config.py`，所以根目录是它的上两级。
2. 定义 `Settings` 类：
   - 在 `__init__` 中从环境变量读取：
     - `LLM_BASE_URL`，默认 `https://api.deepseek.com/v1`
     - `LLM_MODEL`，默认 `deepseek-chat`
     - `LLM_API_KEY`，默认空字符串
   - 定义这些路径属性：
     - `data_dir` → `<项目根>/data`
     - `db_path` → `<项目根>/data/app.db`
     - `chroma_dir` → `<项目根>/data/chroma`
     - `knowledge_dir` → `<项目根>/data/knowledge`
   - 定义 `mock_mode` 属性：没有配置 API Key 时返回 `True`
   - 定义 `ensure_dirs()` 方法：创建 `data_dir`、`chroma_dir`、`knowledge_dir`，已存在时不报错
3. 定义 `get_settings()` 函数，返回一个 `Settings` 实例。

不要在这里读取 `.env` 文件；那是 M3 的事。现在只认操作系统环境变量。

### 3. 编写 `scripts/check_env.py`

功能：
priint
1. 打印 Python 版本和解释器路径。
2. 检查以下包是否已安装：
   `fastapi`、`openai`、`chromadb`、`sentence_transformers`、`streamlit`、`jieba`、`rank_bm25`、`pypdf`、`httpx`
   - 要求用 `importlib.util.find_spec` 检查，**不要真正 import**（真正 import `sentence_transformers` 会加载 torch，很慢）。
   - 已安装打印 `[OK]`，缺失打印 `[MISSING]`。
3. 打印配置：
   - base URL、模型名
   - API Key 只显示“已配置 / 未配置”，**绝不能打印 Key 本身**
   - 当前是否 Mock 模式
   - 各个路径
4. 调用 `ensure_dirs()`，然后确认目录确实存在。
5. 如果有包缺失，程序以非零退出码结束。

### 4. 编写辅助文件

- `requirements.txt`：列出项目依赖。可以先把上面检查的包写进去，版本号暂时不要求精确。
- `.gitignore`：至少忽略 `.env`、`__pycache__/`、`data/app.db`、`data/chroma/`、`.venv/`。
- `README.md`：3-5 句话说明这个项目是什么、当前进行到哪个里程碑。

### 5. 运行

在项目根目录执行：

```bash
cd /d/MyPython/fde_copilot
python -m scripts.check_env
```

## 提示（卡住再看）

- 当前文件路径：`Path(__file__).resolve()`。
- 取父目录：`.parent`；再取一次父目录：`.parent.parent`。
- 环境变量：`os.getenv("LLM_MODEL", "deepseek-chat")`。
- 检查包：
  ```python
  import importlib.util
  exists = importlib.util.find_spec("fastapi") is not None
  ```
- Python 版本：`sys.version`；解释器路径：`sys.executable`。
- 定义只读属性：
  ```python
  @property
  def mock_mode(self):
      return not self.llm_api_key
  ```
- 创建目录：`Path.mkdir(parents=True, exist_ok=True)`。
