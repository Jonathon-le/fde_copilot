# M1：知识库加载与中文分块

> 预计 6-10 小时。目标：把 `data/knowledge/` 里的中文文档读进来，切成可检索的 chunk，并用 CLI 预览结果。

## 先理解：RAG 是什么

RAG = Retrieval-Augmented Generation，直译是“检索增强生成”。它不是某个具体框架，而是一种流程：

1. **加载**：把知识库文档读进来。
2. **切分**：把长文档切成适合检索的小段（chunk）。
3. **建索引**：把 chunk 变成向量存进 Chroma，或建立 BM25 关键词索引。
4. **检索**：用户提问时，找出最相关的 top-k 个 chunk。
5. **生成**：把问题和 chunk 一起交给 LLM，让它基于资料回答，并给出引用。

M1 只做第 1、2 步：**加载 + 切分**。

M1 不需要 embedding、Chroma、LLM，也不需要 LangChain / LlamaIndex。框架只是把上面流程封装起来；先手写一遍，才能理解框架在做什么。本项目关键路径不引入 LangChain。

## 任务

### 1. 准备示例文档

在 `data/knowledge/` 放 3-5 篇中文 Markdown 文档，例如：

```text
data/knowledge/
├─ 退款政策.md
├─ 配送与物流.md
├─ 会员与积分.md
└─ 发票与报销.md
```

每篇建议：

- 一个一级标题；
- 若干二级标题；
- 每节 1-3 段；
- 总长度控制在 1000 字以内，便于调试。

### 2. 实现加载器

建议结构：

```text
app/rag/
├─ __init__.py
├─ loaders.py
└─ chunking.py
scripts/
└─ chunk_preview.py
```

要求：

- 支持 `.md` 和 `.txt`。
- 用 `Path.rglob("*.md")` / `Path.rglob("*.txt")` 递归查找。
- 用 `path.read_text(encoding="utf-8")` 读取。
- 跳过空文件。
- 读取失败时给出明确错误，不要让整个程序静默崩溃。
- 每个文档至少保留：`doc_id`、`title`、`path`、`text`。

提示：`doc_id` 可以用文件名去掉后缀，例如 `退款政策`；后面重新导入时要靠它清理旧 chunk。

### 3. 实现中文分块

要求：

- 先按 Markdown 标题分节：`#`、`##`、`###`。
- 每节再按目标长度切分，建议 300-400 中文字符。
- chunk 之间保留 50-80 字符重叠。
- 尽量在段落或句子边界切，不要从句子中间切断。
- 每个 chunk 保留：

```text
doc_id
title
section
chunk_index
text
source_path
```

- 空 chunk 丢弃。
- 同一输入多次运行，chunk 数量和内容应保持一致。

### 4. 实现 CLI
 
`scripts/chunk_preview.py`：

- 默认读取 `data/knowledge/`；
- 支持命令行参数指定目录，例如 `python -m scripts.chunk_preview data/knowledge`；
- 输出：
  -=每个文档的 chunk 数量；
  - 总 chunk 数；
  - 前 3 个 chunk 的预览，每个截断到 100 字左右；
- 可选：加 `--json`，输出完整 JSONL，方便后续 RAG 使用。

运行方式：

```powershell
cd D:\MyPython\fde_copilot
python -m scripts.chunk_preview
```

### 5. 异常与边界

- 目录不存在：给出提示，非零退出码。
- 目录里没有 `.md` / `.txt`：明确提示。
- 单个文件读取失败：记录错误，继续处理其他文件。
- 编码不是 UTF-8：先按 UTF-8 读取，失败时给出明确错误，不要静默忽略。

## 提示

- `Path.rglob("*.md")` 会递归查找子目录。
- `path.read_text(encoding="utf-8")` 显式指定编码，避免 Windows 默认 GBK 导致乱码。
- `json.dumps(..., ensure_ascii=False)` 保留中文，不变成 `\uXXXX`。
- 按行扫描 Markdown：遇到 `#` 开头的行，开启新 section。
- 切分时优先在 `\n\n` 段落边界切；不够再按 `。`、`？`、`！` 切。
- 可以用 `dataclass` 让字段更清晰，但用普通 `dict` 也可以。
- 不要引入第三方库；M1 只用标准库。
